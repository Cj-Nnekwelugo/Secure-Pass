🔐 **SecurePass — Modern Password Generator**

A modern, responsive password generator built with HTML, CSS, and JavaScript. Generate strong, customizable passwords with real-time strength analysis, clipboard copying, password history, theme switching, and secure client-side generation using `crypto.getRandomValues()`.

**Features:** Password customization • Strength checker • Copy to clipboard • Password history • Presets • Dark/light mode • Responsive design • Local browser storage

🛠️ **Tech:** HTML5 • CSS3 • JavaScript
